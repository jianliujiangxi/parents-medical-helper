# 爸妈异地看病助手 V0.1

一个 **免费、无需注册、尽量不收集个人信息** 的跨省异地就医办事导航器。

首条完整验证线路：**江西参保 → 广东广州就医**。

> 官方负责备案、资格审核、医保结算和待遇计算；本项目只负责把公开规则翻译成“下一步做什么”。

## 已实现

- 7个简单问题判断场景
- 6条核心业务路径：长期居住、转诊、临时外出、异地急诊、已住院未备案、已自费出院
- 门诊慢特病附加校验
- 跨省联网医院附加风险提示
- 每个步骤显示官方依据/官方入口
- 江西→广州首条完整链路
- 可保存 PNG 办事卡
- A4 打印
- 复制文字版给家人
- 长辈模式
- 4个静态可搜索指南页
- 22条原子政策事实
- 20个回归场景 + 附加测试
- 官方来源复核周期检查
- 官方链接检查脚本

## 不做什么

V0.1 明确不做：

- 医疗诊断或医院推荐
- 报销金额/比例承诺
- 代办异地备案
- 身份证、医保号、病历、手机号采集
- AI 自动生成医保政策答案
- 用户账号/云端数据库

## 政策维护原则

1. 关键结论优先只使用国家医保局、医保部门、政府门户等官方来源。
2. 每个来源保存 `verifiedAt` 和复核周期。
3. 具体地方报销比例不在缺乏充分依据时硬编码。
4. 规则变化时先改 `data/`，核心程序尽量不改。
5. 无法确认时给出“向参保地核验”，而不是猜答案。
