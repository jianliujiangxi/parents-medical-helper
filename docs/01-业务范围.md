# V0.1 业务范围冻结

## 服务对象
- 跨省就医的基本医疗保险参保人员及其家属
- 第一条完整线路：江西参保老人到广州就医

## 6条核心路径
1. 长期异地居住，尚未就医
2. 转诊到外省，尚未就医
3. 临时外出就医
4. 异地突发急诊/抢救
5. 已经住院但没有有效备案
6. 已经自费出院

## 附加维度
- 住院 / 普通门诊 / 门诊慢特病
- 备案有效 / 无备案 / 不知道
- 医院联网 / 不联网 / 不知道

## 红线
- 不判断疾病
- 不推荐医院
- 不判断医学上的“急诊抢救”
- 不计算确定报销金额或比例
- 不代办
- 不收身份证、医保号、手机号、病历
