# 静态部署

本项目没有后端数据库，正式构建后全部是静态 HTML/CSS/JS。

## 1. 构建

```bash
npm install
npm run generate
```

产物：

```text
.output/public/
```

## 2. 可选托管方式

任何支持静态站点的服务都可以，例如：

- Cloudflare Pages
- GitHub Pages（适合项目演示/文档）
- 腾讯云/阿里云对象存储静态站点
- 自己已有的 Nginx

如果最终面向中国大陆公众长期使用并绑定大陆服务的自定义域名，请根据实际托管服务和所在地法规处理 ICP 等要求。

## 3. 不需要部署的东西

- PostgreSQL
- Redis
- Python
- Node 运行时服务器
- 用户账号数据库

## 4. 发布策略

建议每次政策规则发布前运行：

```bash
npm run check
npm run check:links
```

然后再上传 `.output/public/`。
