# 政策工程流程

新增一个地方规则包时，必须经过：

1. 找国家统一规则，确认全国底线。
2. 找参保地医保官方规则，记录统筹地区、险种、适用情形。
3. 找就医地官方服务说明，只记录就医地实际承担的信息。
4. 拆成原子事实，每条事实只能表达一个结论。
5. 每条事实绑定官方来源 ID、条款/位置、核验日期。
6. 无法确认的内容标记为“需核验”，不写成确定答案。
7. 为新规则新增回归测试病例。
8. 执行 `npm run check` 后才能发布。

## 建议复核频率
- 官方办理入口：60天
- 国家核心规则：90天
- 地方待遇/材料：30~90天，视变化频率而定

## 失败原则
当地方政策过期、来源失效或互相冲突时：

> 宁可显示“请向参保地医保经办机构确认”，也不要继续使用旧数字。
